개발자의 첫걸음, GitHub 계정 생성 및 잔디 심기 도전

작성일: 2026-03-25 작성자: 정유나 동기부여 기록

1. 개발자의 성지, GitHub에 입성한 정유나

IT 정보 채널이나 선배들의 조언에서 언제나 첫 번째로 강조하던 그 단어, GitHub! 명령어로 제어해야 한다는 사실이 막막했지만 용기를 내서 드디어 저도 첫 개발자 계정을 열고 오픈소스 세계에 발을 들여놓았습니다.

2. Git과 GitHub, 무엇이 달랐을까?

저를 가장 헷갈리게 했던 이 두 단어의 진실을 이제 명확히 설명할 수 있습니다.

  • Git: 내 컴퓨터 로컬 환경에서 마치 타임머신을 타듯 코드의 변경 이력과 버전을 관리해 주는 프로그램.
  • GitHub: 내 컴퓨터의 Git 저장소를 웹상의 클라우드 공간에 올려서, 다른 개발자들과 코드를 쉽게 열람하고 공유할 수 있게 돕는 글로벌 협업 플랫폼.
차이를 깨닫고 나니 검은 터미널에서 git commit -m "First push!"를 타이핑하는 제 손끝이 무척 자랑스러웠습니다.

3. 떨렸던 첫 커밋, 나만의 잔디밭

이번 대학교 첫 HTML 블로그 소스코드를 드디어 제 GitHub 원격 저장소에 업로드했습니다! 푸시 직후 제 프로필 화면에 가득 찬 회색 격자들 중 딱 한 칸이 영롱한 파스텔 초록색으로 빛나는 것을 보았을 때의 쾌감. 인터넷에서 보던 그 '잔디 심기'가 어떤 마력인지 정확히 알게 되었습니다.

4. 지속 가능함을 향해

앞으로 저는 자그마한 자바스크립트 함수 조각이나 알고리즘 문제 1개를 풀었더라도 날마다 무조건 최소 1커밋을 목표로 달려볼 계획입니다.

코딩하다 가끔 길을 잃거나 에러와 싸우느라 지칠 때, 초록색으로 채워진 잔디밭 히스토리를 보면서 포기하지 않고 마음을 다잡겠습니다. 미래의 멋진 시니어 개발자 정유나를 위하여 화이팅! 🌱
